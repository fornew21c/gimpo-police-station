# 5호선 김포경찰서역 신설 데이터 플랫폼

> 구호가 아닌 데이터로. 김포 장기동의 교통복지와 이동권을 위한 정치적 중립 시민 플랫폼.

서울 5호선 김포·검단 연장(김포한강선)은 2026년 3월 예비타당성조사를 통과해 **확정**됐습니다.
다만 감정역~장기역 사이 **4.2km 무정차 구간**에 정차역이 없어, 그 중간에 위치한
**김포경찰서역 신설**의 필요성을 **공공데이터**로 분석·시각화해 촉구합니다.

## 캠페인 성격 — "확정 촉구"

- **본선은 확정**: 방화~한강2지구 25.8km, 정거장 9개소, 총사업비 3조5,587억원, 2033 개통 전망(예타 통과).
- **김포경찰서역은 미확정**: 김포시가 대광위에 건의한 추가 3역(풍무2·김포경찰서·통진) 중 하나로,
  경기도 주관 기본계획 수립 과정에서 경제성·주민편익 근거로 반영 여부가 결정됩니다.
- 따라서 이 플랫폼은 확정된 사실(본선)과 촉구 대상(김포경찰서역)을 명확히 구분해 표기합니다.

## 기술 스택

- **Next.js 16** (App Router) · **React 19** · **TypeScript**
- **Tailwind CSS v4** (`@theme` 토큰 디자인 시스템) · 브랜드 컬러 = 서울 5호선 상징 보라
- **Pretendard** 서체 (CDN) + 시스템 한국어 폰트 폴백
- 차트: 외부 의존성 없는 **순수 SVG 컴포넌트** (`src/components/charts.tsx`)
- **정적 사이트(SSG)** — 외부 DB·환경변수 없이 Vercel에 정적 배포

## 메뉴 구성

| 경로 | 메뉴 | 내용 |
| --- | --- | --- |
| `/` | 홈 | 오늘의 데이터, 현수막 슬로건, 4대 철학, 공약 추적기, 촉구 CTA |
| `/action` | 민원 참여 | 기관별 우선순위(경기도·국토부·김포시), 복사용 민원 제목·본문, 국민신문고 5단계 가이드 |
| `/progress` | 진행현황 | 추진 단계, 인수위 활동백서 원문 지면, 정책 타임라인, 공약 추적기 |
| `/route-map` | 노선도 | 확정 노선 개념도, 김포경찰서역 위치·신설 근거 |
| `/transit` | 교통 데이터 | 김포골드라인 혼잡도(실데이터)·철도 접근성·통행시간 개선 |
| `/analysis` | 데이터 분석 | 인구, 출퇴근 시뮬레이터, 라베니체 상권 효과, 경제효과·소외지수 |
| `/news` | 뉴스 | 실제 보도 링크 모음 |
| `/resources` | 자료실 | 예타 통과 보도·김포시 안내 + 확보 예정 데이터 |

## 데이터에 대하여

지표는 **공개 공공데이터·언론 보도에 근거**하며 각 항목에 출처를 표기합니다.
검증된 값(예타 통과·역간거리·인구·골드라인 혼잡도·상권 공실률·정책 일지 등)만 수치로 표시하고,
실측이 필요한 지표(배차·경제효과·교통 소외지수 등)는 임의값 대신
**"자료 확보 중"**으로 투명하게 표시합니다. 데이터는 `src/data/`에 분리돼 있습니다.

- `src/data/overview.ts` — 비전·철학·오늘의 데이터·캠페인·슬로건
- `src/data/route.ts` — 확정 노선·역·김포경찰서역·신설 근거
- `src/data/transit.ts` — 핵심 지표·통근·김포골드라인 혼잡도·확보예정
- `src/data/analysis.ts` — 시뮬레이터·라베니체 상권 효과·확보예정
- `src/data/civic.ts` — 진행단계·타임라인·공약·뉴스·자료실·인수위 활동백서 인용
- `src/data/action.ts` — 민원 대상 기관·민원 문안·작성 원칙·제출 단계

## 원칙

- **구호가 아닌 데이터** · **집값이 아닌 교통복지** · **정치적 중립** · **객관적 공공데이터**
- 확정 사실과 촉구 대상을 구분하고, 모든 지표는 출처와 기준시점을 표기합니다.
